# Code of conduct

## The short version

Be civil. Assume the other person is acting in good faith. Keep discussion on
the technical question.

## Expected

- Criticise code, designs, and claims. Not people.
- Accept that "no" is a complete answer to a feature request, and that most
  answers here will be no. See [GOVERNANCE.md](GOVERNANCE.md).
- Report bugs without hostility, and receive bug reports without
  defensiveness.
- Respect that this is a single-maintainer project run in finite time.

## Not acceptable

- Harassment, personal attacks, or demeaning comments about anyone.
- Discriminatory language or imagery, including about national origin,
  ethnicity, or dialect. This is a natural-language project; "wrong English"
  arguments about a person's variety of English will be shut down. Dialect
  scope is a documented configuration setting, not a value judgment.
- Publishing private information without consent.
- Sustained pressure after a decision has been made and explained.
- Demanding unpaid labour, or treating maintainer time as an entitlement.

## Scope

This applies to issues, pull requests, discussions, commit messages, and any
project space. It also applies to private correspondence with the maintainer
about the project.

## Enforcement

Report to <<YOUR_EMAIL>>. Reports stay confidential.

The maintainer may, at their discretion and without appeal: edit or delete
comments, lock a thread, close an issue or PR, or block an account. There is no
committee, and no process obligation beyond acting in good faith.
