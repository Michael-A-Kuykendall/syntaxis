Syntaxis is a standalone Rust workspace implementing the M0 deterministic English structural-analysis substrate from Grampan's architecture. Workspace crates: parser-core (model, spans, supports, fact graph, canonical JSON, hashing), english-rules (versioned resource loading, normalization, segmentation, tokenization), conllu (strict CoNLL-U import/export and Penn↔UD mapping), engine-cli (currently stub). M0 intentionally has no POS derivation, dependency parser, grammar rules, corpus gate, or functional CLI. Core invariants: one Analysis snapshot per document; byte-stable canonical serialization; provenance on every fact; transitive support retraction; uncertainty cannot be overstated. Read `mem:tech_stack` for toolchain and `mem:task_completion` for gates.
